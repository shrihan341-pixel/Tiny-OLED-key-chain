# Firmware scaffold

The animation code is not implemented yet because the OLED controller and exact wiring/pin mapping have not been confirmed. Select the matching display library and driver after checking the module datasheet, then add face sprites/animation frames and test on the actual display.

The XIAO ESP32-C3 pin mapping must match the finalized PCB schematic. Avoid assuming that a 1.3-inch OLED uses a specific controller or interface just from its size.
