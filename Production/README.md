# Production checklist

No manufacturing outputs are supplied yet. Add verified exports only after the electrical and mechanical designs are finalized.

- [ ] Export Gerbers and drill files from the checked KiCad board; review them in a Gerber viewer.
- [ ] Record the board revision and fabrication settings.
- [ ] Export separate STL files for the case body and cover from OpenSCAD.
- [ ] Fit-check the actual PCB, display, battery, switch, and wiring before final production.
- [ ] Confirm battery polarity, insulation, strain relief, and safe charging arrangements.
- [ ] Add assembly instructions and tested firmware version.
